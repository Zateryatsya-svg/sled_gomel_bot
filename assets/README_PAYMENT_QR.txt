Сюда нужно положить файл payment_qr.png — это QR-код для перевода вам денег
(тот, что можно сгенерировать в приложении вашего банка: обычно раздел
"Получить перевод" / "Мои реквизиты" / "QR для оплаты").

Как получить такой QR:
1. Откройте приложение своего банка (Альфа-Банк, Беларусбанк, Приорбанк и т.п.)
2. Найдите раздел "Получить деньги" / "Перевод по QR" / "Реквизиты для оплаты"
3. Сохраните картинку QR к себе на телефон/компьютер
4. Переименуйте файл в payment_qr.png и положите в эту папку (assets/),
   заменив этот текстовый файл

Если файла payment_qr.png здесь нет — бот просто не будет присылать
картинку и покажет только текстовую инструкцию с номером карты
(её тоже нужно вписать в content.json -> "payment" -> "intro").

Файл должен называться ТОЧНО payment_qr.png (маленькими буквами).
